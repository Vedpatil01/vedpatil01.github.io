Projects

Multi-agent research assistant

Automated research and report writing

A platform where four agents split the work of researching a topic: one plans the questions, one searches the web, one critiques the findings, and one writes the report.

  • Built the workflow as a four-node LangGraph state machine, with a critique loop that sends weak answers back for another search.
  • Added limits that stop agents from cycling forever and that trim long outputs to stay under API rate limits.
  • Exposed it through an async FastAPI service with Pydantic schemas, and packaged it with Docker so it starts with one script.
